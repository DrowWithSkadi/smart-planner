    Календари

      Google: настройки календаря → «Секретный адрес в формате iCal». iCloud: ⓘ у календаря → «Публичный календарь». Расписание учёбы: ищи кнопку «Экспорт в iCal» или «Подписка».

      Новая задача

      Событие из подписанного календаря — изменить его можно только в источнике.
